Use ALDI List on your devices

Use this page in your browser, or install it for a shortcut and its own app window.

HP Windows computer

Connect to the internet and open this page in Microsoft Edge or Google Chrome.

  • Edge: choose the install icon in the address bar, or open the … menu → More tools → Apps → Install this site as an app. In some versions, Apps is directly in the menu.
  • Chrome: choose the install icon in the address bar, or ⋮ → Cast, save, and share → Install page as app.

Follow the browser’s install prompts. You can then pin ALDI List to your Windows taskbar.

iPhone Home Screen

  1. Open this page in Safari.
  2. Tap Safari’s Share button.
  3. Choose Add to Home Screen, then tap Add.

Saved lists and offline use

After the first successful online load, you can use your list offline. Product links need the internet.

Your quantities, checkmarks, added items and Undo are saved in this browser on this device. Phone and computer edits do not sync; Chrome and Edge also keep separate lists. Use the same browser to return to your saved list.

Use Tab and Shift+Tab to move between controls, Space to check an item, and Enter to use a button. Previous and Next item move focus through the visible items.
